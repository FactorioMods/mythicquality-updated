# Mythic Quality: Updated

Adds higher endgame quality tiers with configurable research costs, scaling and quality odds. Startup options control the singularity tier and its progression.

This fork retains the original high-tier quality progression and supported integrations for Factorio 2.1.24. The Quality mod is required.

Requires Factorio 2.1.24 or later. Disable `MythicQuality` before enabling this fork. Required content and optional integrations are listed in the mod dependencies.
